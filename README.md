# resume

Unity 클라이언트 개발자 이력서 — Jekyll · GitHub Pages

- 테마: [sproogen/modern-resume-theme](https://github.com/sproogen/modern-resume-theme) (remote theme)
- 배포: https://min-omniai.github.io/resume/

## 수정 방법

소개는 `_config.yml`, 섹션 항목은 `_data/*.yml`에서 관리합니다 (경력·프로젝트·스킬·학력·자격·기타).
이미지는 `images/` (프로필·파비콘).

## 로컬 미리보기

```bash
bundle install
bundle exec jekyll serve
```
